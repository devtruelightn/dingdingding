# 파일명 대조표 (한글 이름 → 영문 파일명)

윈도우에서 한글 파일명이 깨지는 문제를 피하려고 파일명을 영문으로 바꾼 판임. 파일 **내용은 모두 한글 그대로**이며, 원본과 동일함.

> 이 저장소로 반입할 때 두 가지가 달라졌음.
> 1. `00_core-prompt.md` → `00_core_prompt.md` (다른 프롬프트 팩과 파일명 규칙을 맞춤)
> 2. `data/` 계층은 반입하지 않음. 앱이 `src/data/curriculum.json`에서 성취기준·성취수준 원문을 꺼내 호출 요청 본문에 실어 보내므로 중복임. 아래 `data/` 행은 원본 패키지의 대조표를 보존한 것이며 이 저장소에는 해당 파일이 없음.
