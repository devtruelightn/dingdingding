# 4학년 1학기 영어 — 학생별 완성 평어 예시(천재교육)

**용도**: 아래 문장은 실제 교사가 사용한 평어 표현 사례임. AI는 이 문장을 그대로 복사하지 말고, 어휘 선택·문장 길이·명사형 종결의 "결"을 학습하여 학생 개별 관찰 기록에 맞게 재구성할 것.

> 평가요소 4개 중 3개를 학생마다 다르게 조합하여 30명분을 생성한 사례임. 영문 표기는 작은따옴표로 감싼 낱말·표현 수준으로만 사용함.

## 부록 — 이 자료를 만든 교사의 실제 프롬프트 (참고용)

아래는 위 30명분 평어를 생성할 때 교사가 사용한 지시문임. 다인원 일괄 생성 시의 조건 설정 방식을 참고할 것.

- 학생 수: 30명
- 과목: 영어
- 평가요소: 4개 중 3개만 무작위로 선택하여 삽입
- 학생 1명당 모든 평가요소가 각각 3문장씩 반드시 포함
- 최종 결과는 학생 1명당 하나의 문단(3~4문장)
- 문장은 줄바꿈하지 말고 이어서 작성하며, 번호로만 학생을 구분
- 별표 같은 특수문자는 삽입하지 않고 전부 작은따옴표로 대체

평가요소 원문(4개)

1. 인사말을 주고받는 표현을 적절한 낱말과 정확한 언어 형식을 사용하여 상대방이 알아듣기 좋은 명확한 발음으로 묻거나 답할 수 있다. (친구를 아침·점심·저녁에 만났을 때의 표현 / How are you 질문에 자신의 상태를 알맞게, 적절한 낱말로, 정확한 언어 형식으로 답하기)
2. 금지하거나 지시하는 표현을 나타내는 여러 가지 낱말을 보고 해당 문장에 맞는 단어를 정확하게 쓸 수 있다. (touch, eat, push, enter, run 등의 뜻을 알고 보기에서 선택 / 알맞은 철자 쓰기 / 알아볼 수 있는 모양으로 정확히 쓰기)
3. 감정이나 상태를 묻는 여러 가지 담화나 문장을 듣고 그 의미를 정확하게 이해할 수 있다. (알맞은 감정 표현 그림 선택 / 알맞은 감정 표현 선택 / 감정 그림에 알맞은 표현을 듣고 식별)
4. 물건의 주인을 묻고 답하는 여러 가지 문장을 읽고 그 의미를 정확하게 이해할 수 있다. (물건을 색으로 표현하는 문장 읽고 정답 표기 / Is this your 표현 읽고 의미 파악 / big, small 등 물건의 상태를 표현하는 문장 읽고 알맞은 답 연결)
