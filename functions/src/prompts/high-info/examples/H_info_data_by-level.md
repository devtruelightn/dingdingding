# 고등학교 정보 데이터 영역 — 성취도(상·중·하)별 세특 예시

**용도**: 아래 문장은 실제 교사가 사용한 세특 표현 사례임. AI는 이 문장을 그대로 복사하지 말고, 어휘 선택·문장 길이·명사형 종결의 "결"을 학습하여 학생 개별 관찰 기록에 맞게 재구성할 것.

> 일반고 보통교과 「정보」 기준임. 특성화고·마이스터고 전문교과 전공실무 과목은 별도 프롬프트가 필요함 (`00_core_prompt.md` §3.2).
> 성취도별 2~3개만 참고할 것.

## 데이터 영역

### 상(우수)

- 공공데이터를 활용해 주제를 선정하고 대용량 데이터를 효율적으로 구조화하는 능력이 뛰어남. 데이터의 특성에 따라 적절한 자료구조를 선택하고, 결측값과 이상값을 정교하게 처리하여 분석의 신뢰도를 높임.
- 데이터 시각화 도구를 활용해 복잡한 데이터를 직관적인 그래프로 표현하고, 이를 근거로 설득력 있는 결론을 도출함. 데이터 분석 결과를 발표하며 논리적으로 근거를 제시하는 능력이 돋보임.
- 여러 출처의 데이터를 통합하고 정제하는 과정에서 데이터 간 불일치를 스스로 발견하여 해결함. 데이터 기반 의사결정의 원리를 이해하고 이를 실제 문제 해결에 적용함.

### 중(보통)

- 실생활 데이터를 수집하고 정제하는 과정에서 결측값과 이상값을 스스로 판별하여 처리함. 표와 그래프를 활용해 데이터를 시각화하고, 이를 근거로 합리적인 결론을 도출하는 능력을 보임.
- 공공데이터를 활용해 주제를 선정하고 데이터를 구조화하는 프로젝트를 수행함. 데이터의 특성에 따라 적절한 자료구조(리스트, 딕셔너리)를 선택하여 처리하는 능력을 보임.
- 데이터의 기본 개념과 수집·정제 과정을 이해하고 실습 과제를 성실히 수행함. 간단한 그래프를 활용해 데이터를 표현하는 능력을 갖춤.

### 하(노력 필요 — 성장 가능성 중심 서술)

- 데이터의 개념을 이해하는 데 어려움을 느꼈으나 예시 자료를 반복해서 살펴보며 점차 이해도를 높여 감. 짝 활동에서 자신의 역할을 성실히 수행하려는 태도를 보임.
- 데이터 정제 실습에서 처음에는 결측값 처리 방법을 어려워했으나 교사의 개별 지도를 통해 기본적인 처리 방법을 익힘. 꾸준히 질문하며 학습하려는 적극적인 태도를 보임.
