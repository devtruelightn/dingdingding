# 고등학교 정보 컴퓨팅 시스템 영역 — 성취도(상·중·하)별 세특 예시

**용도**: 아래 문장은 실제 교사가 사용한 세특 표현 사례임. AI는 이 문장을 그대로 복사하지 말고, 어휘 선택·문장 길이·명사형 종결의 "결"을 학습하여 학생 개별 관찰 기록에 맞게 재구성할 것.

> 일반고 보통교과 「정보」 기준임. 특성화고·마이스터고 전문교과 전공실무 과목은 별도 프롬프트가 필요함 (`00_core_prompt.md` §3.2).
> 성취도별 2~3개만 참고할 것.

## 컴퓨팅 시스템 영역

### 상(우수)

- 컴퓨터 하드웨어와 소프트웨어의 상호작용 원리를 정확히 이해하고, 피지컬 컴퓨팅 실습에서 여러 센서를 조합한 자동화 장치를 독창적으로 설계하여 구현함. 동작 원리를 논리적으로 설명하는 능력이 뛰어남.
- 운영체제의 역할과 프로세스 관리 개념을 정확히 이해하고 이를 실생활 사례에 적용하여 설명함. 네트워크 통신 원리를 학습한 후 간단한 데이터 송수신 프로그램을 스스로 구현함.
- 컴퓨팅 시스템의 문제 해결 과정에서 원인을 체계적으로 분석하는 능력이 돋보임. 임베디드 시스템 프로젝트에서 센서 데이터를 실시간으로 처리하는 프로그램을 완성도 높게 구현함.

### 중(보통)

- 컴퓨터의 하드웨어와 소프트웨어 구성 요소의 역할을 이해하고 문제 상황을 논리적으로 분석하는 능력을 보임. 피지컬 컴퓨팅 실습에서 센서와 액추에이터를 연결하여 간단한 자동화 장치를 구현함.
- 운영체제와 네트워크의 기본 개념을 이해하고 실습 과제를 성실히 수행함. 컴퓨팅 시스템의 작동 원리에 대한 질문을 스스로 만들어 보며 학습을 심화하려는 태도를 보임.
- 피지컬 컴퓨팅 기초 실습에서 회로를 정확히 연결하고 간단한 프로그램으로 장치를 제어함. 어려움이 있을 때 자료를 찾아보며 스스로 해결하려는 태도를 보임.

### 하(노력 필요 — 성장 가능성 중심 서술)

- 컴퓨팅 시스템의 기본 개념을 이해하는 데 다소 시간이 걸렸으나 반복 학습을 통해 점차 개념을 익혀 감. 실습 활동에서 짝과 협력하여 과제를 완성해 나가는 성실한 태도를 보임.
- 하드웨어 구성 요소를 처음 접하며 어려움을 느꼈으나 교사의 설명을 꼼꼼히 필기하고 복습하는 모습을 보임. 간단한 회로 연결 실습에 끝까지 참여하려는 의지를 보임.
