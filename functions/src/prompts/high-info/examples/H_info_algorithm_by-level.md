# 고등학교 정보 알고리즘과 프로그래밍 영역 — 성취도(상·중·하)별 세특 예시

**용도**: 아래 문장은 실제 교사가 사용한 세특 표현 사례임. AI는 이 문장을 그대로 복사하지 말고, 어휘 선택·문장 길이·명사형 종결의 "결"을 학습하여 학생 개별 관찰 기록에 맞게 재구성할 것.

> 일반고 보통교과 「정보」 기준임. 특성화고·마이스터고 전문교과 전공실무 과목은 별도 프롬프트가 필요함 (`00_core_prompt.md` §3.2).
> 성취도별 2~3개만 참고할 것. 프로그래밍 언어명은 영문 표기 예외로 사용 가능하지만, 코드 조각은 문장에 넣지 않을 것.

## 알고리즘과 프로그래밍 영역

### 상(우수)

- 문제 해결 과정을 순서도로 명확히 표현하고 이를 효율적인 프로그램으로 구현하는 능력이 뛰어남. 여러 정렬 알고리즘의 작동 원리를 이해하고 직접 구현하여 시간 복잡도의 차이를 정량적으로 비교·분석함.
- 복잡한 문제를 작은 단위로 분해하여 해결하는 알고리즘적 사고력이 우수함. 파이썬을 활용해 실생활 문제를 해결하는 프로그램을 독자적으로 설계하고, 발생한 오류를 체계적으로 디버깅하여 완성함.
- 반복문과 함수를 조합하여 효율적인 프로그램을 작성하며, 코드의 가독성과 재사용성을 고려하는 태도를 보임. 협업 프로젝트에서 팀원의 코드를 리뷰하고 개선점을 제안하는 능력을 보임.
- 재귀 함수의 개념을 정확히 이해하고 이를 활용해 복잡한 문제를 간결하게 해결함. 알고리즘의 효율성을 개선하기 위해 여러 접근법을 비교하고 최적의 방법을 선택하는 능력이 돋보임.

### 중(보통)

- 문제 해결 과정을 순서도로 표현하고 이를 프로그램으로 구현하는 능력이 우수함. 정렬 알고리즘의 작동 원리를 이해하고 직접 코드로 구현하여 시간 복잡도의 차이를 비교·분석함.
- 반복문과 조건문을 활용하여 간단한 게임 프로그램을 설계하고 구현함. 프로그램 실행 중 발생한 오류를 스스로 디버깅하여 해결하는 문제 해결력을 보임.
- 기본적인 알고리즘 개념을 이해하고 순서도를 작성하는 능력을 갖춤. 파이썬 기본 문법을 활용해 간단한 프로그램을 작성하고 오류를 수정해 나가는 과정에 성실히 참여함.
- 조건문과 반복문을 활용한 프로그래밍 과제를 꾸준히 수행하며 점진적으로 실력이 향상됨. 협업 프로젝트에서 자신이 맡은 부분을 책임감 있게 완성함.

### 하(노력 필요 — 성장 가능성 중심 서술)

- 프로그래밍 기초 문법을 익히는 데 다소 시간이 걸렸으나 예제 코드를 따라 작성해 보며 점차 이해도를 높여 감. 오류가 발생했을 때 포기하지 않고 원인을 찾아보려는 태도를 보임.
- 알고리즘적 사고에 어려움을 느꼈으나 순서도를 그려 보는 연습을 반복하며 문제를 단계별로 나누어 생각하는 방법을 조금씩 익혀 감. 짝과 함께 코드를 작성하며 협력하는 모습을 보임.
- 프로그래밍 실습에서 기본 문법을 이해하는 데 어려움이 있었으나 교사의 개별 지도와 반복 연습을 통해 간단한 프로그램을 완성하는 성취를 이룸.
