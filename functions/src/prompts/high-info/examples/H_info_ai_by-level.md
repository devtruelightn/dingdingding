# 고등학교 정보 인공지능 영역 — 성취도(상·중·하)별 세특 예시

**용도**: 아래 문장은 실제 교사가 사용한 세특 표현 사례임. AI는 이 문장을 그대로 복사하지 말고, 어휘 선택·문장 길이·명사형 종결의 "결"을 학습하여 학생 개별 관찰 기록에 맞게 재구성할 것.

> 일반고 보통교과 「정보」 기준임. 특성화고·마이스터고 전문교과 전공실무 과목은 별도 프롬프트가 필요함 (`00_core_prompt.md` §3.2).
> 성취도별 2~3개만 참고할 것. `AI`는 일반화된 명사로 영문 표기가 허용되나, 특정 상용 서비스의 상호명은 쓰지 않을 것.

## 인공지능 영역

### 상(우수)

- 인공지능의 학습 원리와 데이터 편향 문제를 정확히 이해하고, 분류 문제를 해결하는 모델을 직접 구현하여 성능을 개선해 나가는 과정을 체계적으로 수행함. 인공지능의 사회적 영향을 다각도로 분석하는 능력이 뛰어남.
- 인공지능 활용 사례를 심층적으로 조사하고, 기술의 장점과 한계를 균형 있게 비교·분석하여 발표함. 간단한 머신러닝 모델을 직접 실습해 보며 학습 원리를 체득함.

### 중(보통)

- 인공지능의 기본 개념과 학습 원리를 이해하고, 분류 문제를 해결하는 간단한 모델을 직접 구현해 봄. 인공지능 활용 사례를 조사하고 그 사회적 영향을 균형 있는 시각으로 분석하는 태도를 보임.
- 인공지능의 개념과 활용 분야를 이해하고 관련 자료를 조사하여 발표함. 인공지능이 실생활에 활용되는 사례에 관심을 갖고 꾸준히 탐구하는 태도를 보임.

### 하(노력 필요 — 성장 가능성 중심 서술)

- 인공지능의 개념이 다소 생소하였으나 실생활 사례를 중심으로 설명을 들으며 점차 이해도를 높여 감. 모둠 활동에서 자신의 의견을 제시하려고 노력하는 모습을 보임.
